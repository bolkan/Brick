# BRICK BLAST — Spaccamattoni

Gioco arcade Breakout scritto in HTML, CSS e JavaScript. **Funziona senza server, librerie o installazione** e si pubblica direttamente su GitHub Pages.

## Funzionalità
- Gioco completo con livelli progressivi, punteggio, tre vite iniziali e record salvato nel browser.
- Bonus casuali: barra più grande, pallina rallentata, vita extra.
- Suoni sintetizzati localmente, attivabili/disattivabili.
- Controlli con mouse, tastiera e touchscreen; pausa automatica quando si cambia scheda.
- Layout responsive e tutti i file integrati in `index.html`.

## Come provarlo
Apri `index.html` in un browser moderno (Safari, Chrome, Firefox, Edge).

## Come pubblicarlo su GitHub Pages
1. Crea un repository pubblico su GitHub (ad esempio `brick-blast`).
2. Carica **index.html** nella radice del repository (puoi anche caricare questo README).
3. Apri il repository: **Settings → Pages**.
4. In **Build and deployment** seleziona **Deploy from a branch**, quindi `main` e cartella `/ (root)`. Salva.
5. L'indirizzo del gioco sarà `https://TUO-USERNAME.github.io/brick-blast/`, una volta completata la pubblicazione.

Se possiedi già un sito `TUO-USERNAME.github.io`, inserisci `index.html` in una cartella `brick-blast` nel relativo repository per ottenere `https://TUO-USERNAME.github.io/brick-blast/`.

## Controlli
- **Computer:** frecce sinistra/destra, A/D o mouse; Spazio per lanciare o mettere in pausa; P per la pausa.
- **Telefono/tablet:** tocca per lanciare la pallina e trascina sul campo di gioco per spostare la barra.

## Personalizzazione
Colori, velocità, numero di mattoni e testi sono modificabili nel singolo file `index.html`.
